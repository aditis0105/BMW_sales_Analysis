# 🚗 BMW Global Sales Analysis Dashboard (Power BI)

An interactive Power BI dashboard analysing BMW's global sales from 2010 to 2024, covering regional performance, model revenue, pricing, fuel type, transmission, segmentation, and colour preferences.

---

## 📌 Project Overview

This project provides a comprehensive analysis of BMW's performance across:

- Global sales trends
- Regional performance
- Model-wise revenue
- Pricing behavior
- Fuel type preferences
- Transmission demand
- Market segmentation
- Customer colour preferences

The dashboard has **3 pages**:

1. Executive Overview
2. Detailed Breakdown
3. Additional Insights

## 📂 Dataset Description

The dataset covers BMW's global sales over **14 years (2010-2024)** with multiple vehicle attributes.

| Column | Description |
|---|---|
| Year | Sales year (2010-2024) |
| Region | Continent/Market (Asia, Europe, North America, etc.) |
| Model | BMW models (X1, i3, 3 Series, etc.) |
| Fuel_Type | Petrol, Diesel, Hybrid, Electric |
| Transmission | Automatic / Manual |
| Sales_Volume | Total units sold |
| Total_Revenue | Revenue generated in USD |
| Price_USD | Average price per model/year |
| Mileage_KM | Average mileage |
| Engine_Size_L | Engine capacity (L) |
| Color | Car colour sold |
| Sales_Classification | High-End / Low-End |

This dataset supports trend analysis, segmentation, revenue forecasting, and customer behavior analysis.

## 🧠 Key Business Insights

### 1. Strong Global Performance
- BMW sold **253M units** worldwide (2010-2024).
- Demand stayed consistent, even during economic fluctuations.
- **2022** was the peak sales year.

### 2. Regional Highlights
- Top regions: **Asia & Europe** with 43M sales each.
- North America, Middle East, Africa, and South America: ~42M each.
- **Asia leads in total revenue** (3.3T USD).

> 📌 **Decision Impact:** Prioritize Asia for EV growth and maintain strong hybrid demand in Europe.

### 3. Model Performance
Best-performing models by revenue:

| Model | Revenue (USD) |
|---|---|
| 7 Series | 1.79T |
| 3 Series | 1.77T |
| i8 | 1.76T |
| X1 | 1.75T |

> 📌 **Decision Impact:** Continue focusing on luxury Series models and the hybrid/electric i-series.

### 4. Fuel Type Demand

| Fuel Type | Units Sold |
|---|---|
| Hybrid | 65M |
| Petrol | 63M |
| Electric | 63M |
| Diesel | 62M |

> 📌 **Decision Impact:** The market is shifting toward Hybrid and Electric, supporting BMW's EV roadmap.

### 5. Market Segmentation
- High-End Models: **51%**
- Low-End Models: **49%**

> 📌 A balanced split shows BMW appeals to both luxury and entry-level buyers.

### 6. Pricing Insights
- Average price: **$75,030**
- Prices stayed stable in the 74K-76K range.
- Peak pricing occurred during new model launches.

> 📌 **Decision Impact:** The premium pricing strategy is stable and well accepted globally.

### 7. Transmission Preferences
- Automatic: **127M**
- Manual: **126M**

> 📌 **Decision Impact:** BMW must keep supporting both markets, with a slight tilt toward automatic.

### 8. Colour Preferences
Sales are almost even across Red, Silver, White, Grey, Blue, and Black (~42M-43M each).

> 📌 **Decision Impact:** Colour doesn't strongly influence sales, so production planning can stay flexible.
